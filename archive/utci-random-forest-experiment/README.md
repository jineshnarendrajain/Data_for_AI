This folder contains an earlier exploratory UTCI prediction workflow developed during an intermediate stage of the project.

The workflow used train/validation/test splits and Random Forest modelling to predict UTCI values.

After project review and alignment with the final brief, the project direction was consolidated into:

Manhattan Urban Heat Hotspot Prioritisation

using:

- Landsat 8 Land Surface Temperature (LST)
- Sentinel-2 NDVI
- Heat Risk Analysis
- Hotspot Identification

The archived files are retained for transparency and project traceability.
